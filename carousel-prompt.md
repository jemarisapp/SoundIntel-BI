# LinkedIn Carousel Design Prompt

Create a professional LinkedIn carousel PDF (8 slides, 1080x1080px each) for SoundIntel BI, an AI-powered music analytics platform.

## ⚠️ CRITICAL FIGMA INSTRUCTIONS:
**CREATE 8 SEPARATE FRAMES/ARTBOARDS - NOT ONE COMBINED PAGE**

- Each slide MUST be its own individual 1080x1080px frame
- Name frames: "Slide 1", "Slide 2", "Slide 3", etc.
- Arrange frames horizontally in Figma for easy navigation
- DO NOT combine all slides into one long vertical page
- Each frame should be independently exportable as a single image
- When exporting to PDF, export all 8 frames as separate pages in the PDF
- This is a CAROUSEL - each slide needs to be a distinct, swipeable page

## Design Philosophy:
**MINIMAL. APPLE-INSPIRED. LET THE PRODUCT SPEAK.**

- The dashboard UI should carry the visuals
- Extreme whitespace (or dark space)
- Minimal text overlays
- Let screenshots breathe
- Clean, sans-serif typography (SF Pro, Inter, or similar)
- No unnecessary decorations

## Design Style:
- Dark theme with deep blacks (#0c0c0c background)
- Accent colors: Indigo (#6366f1), Green (#10b981), Blue (#0ea5e9), Gold (#f59e0b)
- Maximum 2-3 lines of text per slide
- The product is the hero

## Technical Specs:
- **Dashboard screenshots: 1920x1080px**
- **All image placeholders should be 1920x1080 aspect ratio**
- Slides: 1080x1080px (Instagram carousel format)

## Design Execution Notes:
- **Let the 1920x1080 screenshots be the star**
- Use dark backgrounds (#0c0c0c) to match dashboard theme
- Text should be white or subtle gray
- Don't add borders, shadows, or decorations to screenshots
- If screenshot doesn't fill the square, center it with dark space around it
- Typography: Large headings (48-72pt), small body text (18-24pt)
- Alignment: Center everything or use consistent left alignment
- The dashboard is already beautiful—don't compete with it
