# LinkedIn Post: SoundIntel BI Launch Investigator

Bridging the gap between Creative, Data, and AI.

I recently rebuilt SoundIntel BI from the ground up, transforming it from a static Power BI dashboard into a custom full-stack analytics platform.

The breakthrough? The Launch Investigator: an AI-powered assistant that explains the "why" behind Billboard Hot 100 chart movements.

What makes it different:

🎯 Context-Aware AI Analysis  
The Investigator analyzes the complete performance mix (streaming, airplay, sales) across all 100 songs to explain why tracks rise or fall, identifying whether a song is streaming-led, airplay-driven, or sales-boosted.

💬 Natural Language Insights  
Built an interactive chat interface powered by Gemini API that handles queries like "Why did this song drop?" or "Which tracks are climbing on streaming?" and delivers data-driven explanations with visualizations.

⚡ Modern Tech Stack  
Architected with React + TypeScript, Supabase (PostgreSQL), and Recharts for real-time interactivity. Migrated from a SQL/Python pipeline to a production-grade web app optimized for speed and insight delivery.
